## About Me

I'm a Computer Science Teacher at the [Military Lyceum of Hetman Petro Sahaidachnyi National Army Academy](https://vlnasv.mil.gov.ua/) and a programming instructor for children at [IT-Elit](https://www.instagram.com/it_elit_school/).

I combine education, software development, and visual creativity. My work focuses on building practical digital tools, educational resources, web applications, and interactive projects.

## What I Work On

- Educational software and interactive learning materials
- Web applications and digital services
- Interactive dashboards and data visualization
- Frontend and backend development
- Graphic design and multimedia projects
